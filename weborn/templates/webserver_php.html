How PHP-FPM Works

PHP-FPM (FastCGI Process Manager):
1. Nginx menerima request untuk file .php
2. Nginx meneruskan ke PHP-FPM via unix socket
3. PHP-FPM memproses file PHP → output HTML/JSON
4. Nginx mengembalikan response ke client
Pool config: /etc/php/*/fpm/pool.d/
