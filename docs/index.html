App Deployment Flow

Browser → Nginx → Gunicorn → UvicornWorker → FastAPI/Flask/Django

Email Flow

Postfix (SMTP) → Dovecot (IMAP) → Rspamd (filter) → OpenDKIM (sign)

Security Flow

UFW (firewall) → Fail2Ban (brute-force) → ClamAV (malware) → Certbot (SSL)
